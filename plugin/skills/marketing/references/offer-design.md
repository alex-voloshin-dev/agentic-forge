# Offer design (marketing sub-procedure)

Design, strengthen, or price an offer — the packaging that makes the product's value obvious —
using the Grand Slam Offer method (Alex Hormozi, *$100M Offers*; summarized here, adapted to this
skill's evidence discipline). The goal is a category-of-one offer sold on value, not price.
**Not** demand generation (channels/ads — that is [strategy.md](strategy.md)).

## Gather essentials first (one short batch, only what's missing)

1. The product/service and the core result it delivers. 2. Target segment and their sharpest
pain. 3. Current price/pricing model. 4. **Proof assets** (case studies, metrics, testimonials —
these back "likelihood" later). 5. Hard constraints (margin floor, delivery capacity, legal).
Infer the rest from context and **mark every inference as an assumption** — never invent margins,
capacity, or results.

## Build sequence

1. **Value equation.** Value = (Dream Outcome × Perceived Likelihood) ÷ (Time Delay × Effort &
   Sacrifice). Raise the top: state the outcome concretely; back likelihood with the *real* proof
   assets, not adjectives. Lower the bottom: faster time-to-value, less user effort.
2. **Stack.** List every problem/fear the segment has on the way to the outcome → turn each into
   a solution component → **trim & stack**: keep high-client-value / low-cost-to-deliver
   components; cut expensive-and-low-value ones.
3. **Price structure.** Premium target; pick the structure (access / consumption / outcome-based);
   respect the margin floor; lock the number only after the stack is built. Payment terms are part
   of the offer (lower the buy barrier without discounting the headline).
4. **Risk reversal.** A concrete guarantee the business can actually honor (conditional or
   unconditional); name what triggers it.
5. **Scarcity & urgency — the authenticity guardrail.** Only REAL constraints (actual capacity,
   an actual cohort date, a real price change). **No fake timers, no invented "2 spots left"** —
   fabricated scarcity is the offer-design equivalent of an invented benchmark and fails the
   claims pass.
6. **Name it.** Make the outcome and the audience legible in the name (magnetic reason-why,
   avatar, goal, interval, container — the MAGIC mnemonic); skip components that would force a
   false claim.

## Output

Two parts, always: **A — the offer** (name; who it's for; the stack with anchor values; price and
terms; the guarantee; real scarcity/urgency if any) and **B — the rationale** (how each value
lever is addressed; which claims rest on which proof assets; the assumptions made). The
adversarial claims pass from SKILL.md applies: every number cited or marked an assumption; no
unsupported superlatives; scarcity claims must name their real constraint.
