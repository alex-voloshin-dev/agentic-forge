# Architecture Decision Records

Each ADR captures one significant decision: its context, the choice, the alternatives
weighed, and the consequences. ADRs are immutable once accepted; supersede rather than
edit — with one convention: a later ADR may add a dated, italicised amendment *in place* next to
a claim it retracts or completes (ADR 0090 §Decision 4); the original text is never rewritten.
